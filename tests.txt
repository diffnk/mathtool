ТЕСТЫ ПРИЛОЖЕНИЯ mathtool.py
=============================================================================

(либо python mathtool.py solve и ввод A, B, C с клавиатуры)

| 2  | 1      | -2     | 1     | Квадратное; D = 0; x = 1.000                                | 0   |
| 3  | 1      | 0      | 5     | Квадратное; D = -20; действительных корней нет              | 0   |
| 4  | 0      | 2      | -4    | Линейное; x = 2.000                                         | 0   |
| 5  | 0      | 0      | 0     | Ошибка (stderr): не уравнение, неизвестное отсутствует      | 1   |
| 6  | 0      | 0      | 7     | Ошибка (stderr): не уравнение, неизвестное отсутствует      | 1   |
| 7  | abc    | 1      | 1     | Ошибка (stderr): коэффициент не является целым числом       | 1   |
| 8  | 50000  | 1      | 1     | Ошибка (stderr): значение вне допустимого диапазона         | 1   |
| 9  | 1      | 1      | -1    | Квадратное; D = 5; x1 = 0.618; x2 = -1.618                  | 0   |
| 10 | 1.5    | 1      | 1     | Ошибка (stderr): коэффициент не является целым числом       | 1   |
| 11 | 1      | -50000 | 1     | Ошибка (stderr): значение вне допустимого диапазона         | 1   |
| 12 | 1      | 1      | 10001 | Ошибка (stderr): значение вне допустимого диапазона         | 1   |
| 13 | 10000  | -10000 | 10000 | Квадратное; D = -300000000; действительных корней нет       | 0   |

| 15 | 0      | 5      | 0     | Линейное; x = 0.000                                         | 0   |

Тесты 10-15 — дополнительные: дробное число, граничные значения диапазона
(10000 допустимо, 10001 — нет), отсутствие вывода «-0.000».

ЧАСТЬ 3. Тесты в свободной форме

№ 21. Вызов справки без параметров
  Команда:  python mathtool.py
  Ожидается: вывод справки (назначение и способы запуска); код возврата 0.

№ 22. Вызов справки с параметром --help
  Команда:  python mathtool.py --help
  Ожидается: вывод справки; код возврата 0.

№ 23. Неизвестная команда
  Команда:  python mathtool.py foo
  Ожидается: в stderr «ОШИБКА: неизвестная команда 'foo'»; код возврата 1.

№ 24. Пропущен параметр (не хватает -c)
  Команда:  python mathtool.py solve -a 1 -b 2
  Ожидается: в stderr «ОШИБКА: неверный набор параметров»; код возврата 1.

№ 25. Лишний параметр
  Команда:  python mathtool.py solve -a 1 -b -3 -c 2 extra
  Ожидается: в stderr «ОШИБКА: неверный набор параметров»; код возврата 1.

№ 26. Неизвестный параметр вместо -a
  Команда:  python mathtool.py solve -x 1 -b 2 -c 3
  Ожидается: в stderr «ОШИБКА: неизвестный параметр (ожидается -a, -b, -c)»;
             код возврата 1.

№ 27. Разделение потоков вывода при ошибке
  Команда:  python mathtool.py solve -a abc -b 1 -c 1 2>$null      (PowerShell)
  Ожидается: на экране ничего не выводится (сообщение ушло в stderr); код 1.


ПРОВЕРКА КОДА ВОЗВРАТА
  PowerShell:  python mathtool.py solve -a abc -b 1 -c 1
               $LASTEXITCODE
  cmd:         python mathtool.py solve -a abc -b 1 -c 1
               echo %ERRORLEVEL%
